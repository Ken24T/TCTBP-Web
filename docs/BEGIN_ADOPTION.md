# Shared Begin distribution

The factory carries the complete pinned TCTBP Begin runtime, native skill,
provenance, contract and Node conformance fixtures. Newly scaffolded projects
start in inspect mode with no enrolled remote: a project owner must deliberately
declare its repository identity and capabilities before action-capable resume.
The generic factory never installs application-specific ticket/settings adapters.

The managed-surface inventory, workflow catalogue, activation metadata and
reconcile instructions move together. Begin is public without changing the
established Adviser v1 vocabulary. Consumer tests cover the real offline scaffold
path and demonstrate that the generated Begin entry is self-contained.

## Incremental design review

The existing large scaffold runner remains intact. Its change is a small copy
seam calling the managed-surface inventory; project profile generation stays in
the existing profile module. Keeping its prompt/answer and filesystem transaction
together preserves the established scaffold behaviour. The large workflow
catalogue remains a single auditable declaration of runner/trigger coverage;
Begin adds one cohesive entry rather than a parallel catalogue. The TCTBP Agent
reference remains coherent, with a short route to the detailed shared contract.
No unrelated policy fields, release workflows or development-policy bytes change.
